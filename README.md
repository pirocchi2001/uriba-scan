# 売場スキャン（Web版）

Android版「売場スキャン」をブラウザで動くようにしたものです。iPhone・Android のどちらでも使えます。
GitHub Pages で無料公開できます（サーバー不要）。

## 使い方

1. スマホのブラウザ（iPhone は Safari、Android は Chrome）で公開URLを開く
2. **ホーム画面に追加**する（iPhone：共有ボタン →「ホーム画面に追加」／Android：メニュー →「ホーム画面に追加」）
3. ホーム画面のアイコンから開き、「転送.xlsx を選ぶ」でマスターを読み込む
4. 「スキャン開始」でカメラを起動してスキャン
   - マスターにある商品：**◯**・商品名・在売価（税込）
   - マスターにない商品：**該当なし**
5. 「Excel出力して保存」→「共有・保存」で Google ドライブ等へ保存

> iPhone では、Safari で開いた場合とホーム画面から開いた場合でデータの保存場所が別になります。
> マスターの読み込みは、実際に使うほう（ホーム画面のアイコン）から行ってください。

## マスターデータについて

- マスター（転送.xlsx）は**各端末の中だけ**に保存され、GitHub やインターネット上には置きません。
- 読み込むのは全シートの D列=JAN、E列=品番名、F列=在売価（税込）です。見出し行はあってもなくても構いません。
- 更新するときは、画面下の「マスター ○件」をタップ →「転送.xlsx を読み込み直す」。
- `.gitignore` で `*.xlsx` などをリポジトリに入れないようにしています。

## Android版との違い

- 画面タップでのピント合わせはありません（端末のオートフォーカスに任せます）。
- iPhone はバイブが鳴りません。ライト（トーチ）・光学ズームは端末とブラウザが対応している場合のみ。ズーム非対応の端末では画面上の拡大になります。
- 起動時の動画はありません。

## 更新の公開

ファイルを変更して `main` に push すると、GitHub Pages に自動で反映されます。
端末側に古い版が残る場合があるので、更新時は `sw.js` の `CACHE` の番号（`uriba-scan-v1` → `v2`）も上げてください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面と処理 |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応・ホーム画面アイコン |
| `vendor/` | ライブラリ（SheetJS：Excel読み書き、barcode-detector + zxing-wasm：iPhone用バーコード読み取り） |
