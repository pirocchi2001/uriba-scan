# 売場スキャン（Web版）

Android版「売場スキャン」をブラウザで動くようにしたものです。iPhone・Android のどちらでも使えます。
GitHub Pages で無料公開できます（サーバー不要）。

## 使い方

1. スマホのブラウザ（iPhone は Safari、Android は Chrome）で公開URLを開く
2. **ホーム画面に追加**する（iPhone：共有ボタン →「ホーム画面に追加」／Android：メニュー →「ホーム画面に追加」）
3. ホーム画面のアイコンから開き、パスワードでログイン（端末ごとに最初の1回だけ）
   - ログインするとマスターが自動で読み込まれます
4. 「スキャン開始」でカメラを起動してスキャン
   - マスターにある商品：**◯**・商品名・在売価（税込）
   - マスターにない商品：**該当なし**
   - 転記できるよう、**OK を押すまで表示したまま**（その間は次のスキャンを止めます）
5. 「Excel出力して保存」→「共有・保存」で Google ドライブ等へ保存

> iPhone では、Safari で開いた場合とホーム画面から開いた場合でデータの保存場所が別になります。
> ログインは実際に使うほう（ホーム画面のアイコン）で行ってください。

## マスターデータ（暗号化）について

- 公開しているのは暗号化済みの `master.enc` だけです。転送.xlsx そのものはリポジトリに入れません（`.gitignore` で除外）。
- `master.enc` はログインパスワードから作ったカギ（PBKDF2 60万回 → AES-256-GCM）で暗号化しており、パスワードを知らない人には中身が読めません。
- 読み込むのは全シートの D列=JAN、E列=品番名、F列=在売価（税込）です。

### マスターを更新するとき

```sh
MASTER_PASSWORD='ログインパスワード' node tools/encrypt-master.js ~/Downloads/転送.xlsx
git add master.enc && git commit -m "マスター更新" && git push
```

各端末は次に開いたとき（または画面下の「マスター ○件」→「最新のマスターを取得」）で自動的に新しいマスターになります。

### パスワードを変えるとき

新しいパスワードで上のコマンドを実行して push するだけです。各端末は次に開いたときに再ログインを求められます。

## Android版との違い

- 端末で転送.xlsx を直接読み込むこともできます（「マスター ○件」→「端末の転送.xlsx を読み込む」）。
- 画面タップでのピント合わせはありません（端末のオートフォーカスに任せます）。
- iPhone はバイブが鳴りません。ライト（トーチ）・光学ズームは端末とブラウザが対応している場合のみ。ズーム非対応の端末では画面上の拡大になります。
- オープニング動画は容量を減らすため画質を下げています（432×768・約0.43MB）。iPhone等では音なしで再生されます。

## 更新の公開

ファイルを変更して `main` に push すると、GitHub Pages に自動で反映されます。
端末側に古い版が残る場合があるので、更新時は `sw.js` の `CACHE` の番号（`uriba-scan-v1` → `v2`）も上げてください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面と処理 |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応・ホーム画面アイコン |
| `master.enc` / `master-parse.js` / `tools/encrypt-master.js` | 暗号化済みマスター・xlsx読み取り・暗号化ツール |
| `vendor/` | ライブラリ（SheetJS：Excel読み書き、barcode-detector + zxing-wasm：iPhone用バーコード読み取り） |
